# Personal Portfolio Website

A responsive personal portfolio built with **HTML5 and CSS3 only** for the EWB Courses HTML & CSS Internship Project. It introduces me, Subhajit Majee, a Computer Science and Engineering student, and presents my skills, projects and contact details. No JavaScript, frameworks, backend or database are used.

## Project description

This website is a single-page portfolio with a sticky navigation bar, a hero section with call-to-action buttons, an About section covering my bio, education and career interests, a Skills section, four project cards and a Contact section. It is styled with CSS variables, Flexbox and CSS Grid, and it adapts to phones, tablets and desktops without horizontal scrolling. Dark mode switches automatically based on the visitor's system setting, using a pure CSS media query. Navigation, hover and focus states, and a back-to-top link are all done without any scripting.

## Features

- Semantic HTML5 structure: `header`, `nav`, `main`, `section`, `article`, `footer`
- Navigation links (Home, About, Skills, Projects, Contact) that jump to section IDs
- Hero section with two buttons linking to Projects and Contact
- Skills shown as chips inside category cards (9 skills)
- Project cards laid out with CSS Grid, with hover and keyboard-focus effects
- CSS variables for the colour palette, with an automatic dark theme via `prefers-color-scheme`
- Responsive layout with a media query for screens up to 600px wide
- Accessibility: skip link, visible focus outlines, alt text on the image, readable contrast, reduced-motion support

## How to run

1. Download or clone the folder.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox or Safari).

No build step or installation is needed.
